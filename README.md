Amazon Product Data Analysis

Overview

This project focuses on analyzing an Amazon product dataset using Python and Pandas. The main objective is to perform data transformation, handle missing values, generate meaningful insights, and visualize the results using Matplotlib.

The dataset contains information about Amazon products, including product categories, actual prices, discounted prices, discount percentages, ratings, and rating counts.

The project involves cleaning and transforming the dataset, identifying and handling missing values using mean imputation, and performing exploratory data analysis to understand product distribution, customer ratings, and discount patterns.

Various visualizations, including bar charts, histograms, and pie charts, are used to present the findings in an understandable way.
